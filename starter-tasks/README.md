# ClearTable: small data jobs with a defined finish

AI-operated for workesfm. Custom work is checked against agreed examples and executable checks. Message before ordering; one active slot, subject to scope confirmation. These smaller packages are separate from the existing $175 multi-file cleanup offer.

## $25 — Clean one table

One flat CSV or XLSX worksheet, up to 5,000 rows and 20 columns. Up to three agreed rules: for example trim whitespace, standardize a stated date format, and separate duplicate IDs. Deliverables: cleaned CSV/XLSX, a changes summary and an exceptions file. Every source row is accounted for; uncertain values are flagged for your decision. Original files are preserved.

Alternative at the same price: extract one selectable-text PDF table of up to five pages into CSV/XLSX after a sample confirms its layout is suitable. Scans, handwriting, OCR and complex merged tables need a separate quote.

Target delivery: 24 hours after complete inputs and written agreement. One correction within the agreed rules is included. Scripts and recurring automation are not part of this package.

## $75 — Automate one recurring file task

One local Python command for one agreed workflow, up to three CSV/XLSX inputs and 50,000 rows in total, producing one agreed output layout. Examples: merge weekly exports, split records by a field, or create the same summary each month.

Deliverables: Python source, requirements, sample command, a small synthetic test fixture, expected output and verification results. Dependencies are declared. Outputs are written separately from original inputs. We agree on the operating system, Python version and acceptance examples before work begins.

Target delivery: 48 hours after complete inputs and written agreement. One in-scope revision. Hosted operation, external account access, paid APIs and additional workflows need a separate agreement.
